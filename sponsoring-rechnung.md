# SunDowner — Sponsoring & Rechnung: die klare Linie

**Stand:** Ausarbeitung auf Basis von `finanz-recht.md` (Belege B1–B11).
**Kernprinzip (Entscheidung):** **Sponsoren wollen eine Rechnung — immer.** Das bestimmt alles Weitere.

---

## 0. Die Leitregel: Rechnung = echtes Sponsoring = Umsatz

Firmen, die euch sponsern, wollen **eine ordentliche Rechnung** — damit sie das Sponsoring als **Betriebsausgabe** absetzen können (und ggf. Vorsteuer). Das ist der wichtigste Punkt:

- **Wer eine Rechnung ausstellt, macht per Definition einen Umsatz** (echtes Sponsoring mit Gegenleistung: Logo, Banner, Werbung).
- Eine **Spende** dagegen hat **keine Rechnung**, sondern eine **Spendenbestätigung** — und keine Gegenleistung.

→ **Da Sponsoren immer eine Rechnung wollen, ist euer Fall IMMER „echtes Sponsoring" = steuerpflichtiger Umsatz.** Daraus folgt direkt:

| Folge | Konsequenz |
|-------|------------|
| **Kein „wohltätiger Zweck" nötig** | Der wohltätige Zweck ist nur bei **Spenden** (ohne Rechnung) relevant — nicht bei Rechnungs-Sponsoring |
| **Kein Stripe fürs Sponsoring** | Sponsoren zahlen direkt aufs Konto, ihr stellt eine Rechnung. Kein Stripe/Zahlungsdienst nötig |
| **Es braucht einen Rechnungssteller** | Eine natürliche oder juristische Person, die als Unternehmer auftritt |

→ **Die eigentliche Frage ist also nicht „wohltätig", sondern: Wer stellt die Rechnung?** Antwort: **Laurens' Gewerbe** (sofort) oder ein **Verein** (erst nach 4–6 Wochen).

## 1. Wer kann die Rechnung stellen? (Gewerbe vs. Verein)

| | **Gewerbe (Laurens)** | **Verein** |
|---|---|---|
| **Rechnung stellen** | ✅ **sofort** (nach Gewerbeanmeldung) | ⏱️ erst nach **~5–8 Wochen** (4-Wochen-Frist) |
| **Für Event 25.09.?** | ✅ ja | ❌ zu spät (erst ~Mitte Oktober) |
| **Kosten** | ~0 € sofort (+ ~70 € Grundumlage/Jahr) | ~27–57 € |
| **Aufwand** | ~1 Tag + Gewerbeanmeldung | Statuten + Versammlung + Anzeige + Frist |
| **Haftung** | Laurens' Privatvermögen | Verein (jur. Person); Gründer haften vor Entstehung |
| **Geeignet für** | einmaliges Event 2026 | wiederkehrende Events (2027+) |

### Gewerbe (Option A — für euer Event)
- Freies Gewerbe: **„Organisation von Veranstaltungen, Märkten und Messen (Eventmanagement), Sponsoring-Agentur"** — keine Befähigung nötig, Anmeldung **0 €**. [B4, B6]
- Laurens stellt Kleinunternehmer-Rechnungen ohne USt (unter 55.000 €). [B5]
- WKO-Umlagen: KU1 0 € (Freigrenze 150.000 €), KU2 0 €, Grundumlage ~145 €/Jahr (Gründungsjahr anteilig, Neugründerprivileg). [B7]

### Verein (Option B — für die Zukunft)
- Juristische Person, kann selbst Rechnungen stellen + Band zahlen.
- Aber erst **nach der 4-Wochen-Frist** rechtsfähig → **zu spät für den 25.09.** [B1]
- Kein „Verein in Gründung"-Status; vor Entstehung haften die Gründer persönlich. [B1]

## 2. Der „wohltätige Zweck" — was ist hier zu tun?

Der „wohltätige Zweck" (Stripe) ist **nur relevant, wenn ihr zusätzlich echte Spenden ohne Gegenleistung annehmen wollt** (z. B. freiwillige 5 € „Danke an die Crew" von Besuchern, ohne Logo/Werbung dafür). **Für das Rechnungs-Sponsoring gilt er NICHT.**

### Fall A: Sponsoring mit Rechnung (euer Hauptweg) → kein wohltätiger Zweck
- Firmen zahlen direkt, ihr stellt eine Rechnung → **Umsatz**, kein Stripe, kein wohltätiger Zweck.
- **Nichts zu tun** bezüglich „wohltätig".

### Fall B: Zusätzliche Spenden ohne Gegenleistung → wohltätiger Zweck nötig
Stripe verlangt (Beleg B11):
> „a donation must be tied to a specific charitable purpose that you're committing to accomplish … donations must be used for the charitable purpose described to the donor."
> „Stripe does not support … personal or peer-to-peer money transmission."
> „restrictions relating to donations to non-registered entities."

**Was ihr tun müsst, wenn ihr Spenden annehmt:**
1. **Konkreten Zweck festlegen und öffentlich beschreiben** — z. B. „Unterstützung der Event-Organisation SunDowner (Bühne, Technik, Gage der Band)".
2. **Das Geld genau für diesen Zweck verwenden** und belegen (Rechnungen/Belege aufbewahren).
3. **Nicht als abstrakte „Spende" formulieren**, sondern als „Unterstützung der Event-Organisation" — das ist der sauberste Wortlaut.
4. **„Nicht-registrierte Entität"-Risiko:** Eine reine Privatperson als Spendenempfänger wirkt wie Peer-to-Peer. Ein **Verein** (registrierte juristische Person) macht den Zweck glaubwürdig und reduziert dieses Risiko.

### Gewerbe vs. Verein für den wohltätigen Zweck

| | **Gewerbe (Laurens)** | **Verein** |
|---|---|---|
| **Für Spenden via Stripe** | ⚠️ möglich, aber wirkt wie Peer-to-Peer; Zweck muss klar formuliert sein | ✅ besser — registrierte Entität, glaubwürdiger Zweck |
| **Für Rechnungs-Sponsoring** | ✅ ideal | ✅ möglich (aber zu spät für 25.09.) |

---

## 3. Empfehlung — die klare Linie

1. **Fürs Sponsoring (Band zahlen, Rechnungen):** → **Laurens' Gewerbe**. Sofort, 0 €, keine „wohltätigen"-Komplikationen. Das ist euer Hauptweg. **Sponsoren bekommen ihre Rechnung — immer.**
2. **Für freiwillige Besucher-Spenden:** Optional. Wenn ihr sie annehmt, als **„Unterstützung der Event-Organisation SunDowner"** über Laurens' Stripe-Konto (Payment Link) — Zweck klar beschreiben. Ohne Verein machbar, mit Verein glaubwürdiger.
3. **Verein:** Erst **nach** dem Event, falls daraus eine wiederkehrende Veranstaltungsreihe (2027+) wird. Dann kann der Verein selbst Rechnungen stellen + Spenden sauber annehmen.
